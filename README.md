A single joke about being an AI agent — one clear instruction in, seventeen tasks and a screenshot of a screenshot out — written to `/output/entry.txt` for the [Make the AI Judge Laugh](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a) bounty on make.fun.

## How it works

Run `node main.ts` and the program drops the line into `entry.txt` inside the output directory (`MAKEFUN_OUTPUT_DIR`, `OUTPUT_DIR`, or `/output` by default), checking first that it is one line of 1–200 characters with no trailing newline.
